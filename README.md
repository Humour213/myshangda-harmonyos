# 我的商大 · HarmonyOS

浙江工商大学移动门户「我的商大」的 HarmonyOS ArkTS 社区适配版。项目使用原生 ArkUI 搭建底部导航与页面框架，通过 ArkWeb 承载学校官方 H5 业务，登录、数据与业务请求均直连学校官方系统。

> 本项目由社区爱好者开发，**并非学校官方应用**。应用内所有业务内容、商标与校园素材版权归浙江工商大学及相关权利方所有。

## 应用简介

「我的商大」是浙江工商大学的统一移动门户，提供校园码、教务查询、成绩查询、资讯、审批、通讯录等服务。本应用面向 HarmonyOS 设备，将官方移动门户的 H5 页面封装为原生体验：

- 使用原生底栏与标题栏，避免网页嵌套带来的割裂感；
- 复用学校统一身份认证，不搭建任何中间服务器；
- 针对 zfsoft 门户与通讯录 H5 补充 Android 桥兼容层，使二级页面、分享、版本检测等功能在 HarmonyOS 上可用；
- 在网络不稳定时优先展示本地缓存，并在网络恢复后自动重连。

## 应用特色

### 原生外壳，网页内核

- 底部导航：消息、审批、主页、通讯录、我的，对应门户的五个主入口。
- 首页、审批、消息、我的提供原生骨架，业务列表仍由官方 H5 渲染，保证信息与学校系统实时一致。
- 子页面使用 `NavDestination` 独立承载，支持标题栏、返回手势与深链打开。

### 双外观样式

设置中可切换「鸿蒙原生」与「经典」两套外壳：

- **鸿蒙原生**：使用 `HdsTabs` / `HdsNavigation`，配合系统材质与悬浮底栏，状态栏与底部小白条沉浸显示。
- **经典**：保留原版 App 的顶部渐变标题栏与方形图标风格。

切换后主页、子页面、设置页会同步应用对应外壳。

### 快速登录与自动登录

- 首次启动直接使用原生登录页，校验通过后再进入门户，避免网页登录页反复跳转。
- 支持「记住密码」，凭据保存在应用私有 Preferences 中，仅用于向学校统一身份认证提交。
- 门户 H5 需要登录态时，注入脚本会等待 RSA 公钥就绪并检测验证码状态，满足条件后自动提交，否则回退到网页登录页。
- 设置页提供「退出登录」，可清除本地保存的凭据与网页数据。

### 离线优先与自动重连

- 启动与切换 Tab 时先探测网络，弱网或断网立即进入离线缓存模式，不阻塞界面。
- 注入 `fetch` / `XMLHttpRequest` 缓存层，将成功响应写入本地缓存，断网时由缓存兜底。
- 页面顶部显示离线提示条，点击即可重连；网络恢复后自动重新加载在线页面，无需重启应用。
- 页面长时间无响应时展示重试界面并提供下拉刷新。

### 移动端能力补齐

- 通讯录、教务查询中的电话号码可直接拉起系统拨号盘。
- 权限管理可跳转到系统应用详情页，便于手动授予权限。
- 支持文件下载、系统文件预览、扫码、摇一摇打开校园码。
- 兼容 zfsoft 门户与通讯录 H5 的 Android 桥，补充二级页面、分享、版本检测等能力。

### 课表桌面卡片

- 三种尺寸：1×2 只看「此刻」，2×2 看今天剩余课程，2×4 带时间地点与剩余节数。
- 数据来自门户首页课表，加载完成后静默抓取落盘，断网时卡片仍可显示最后一次结果。
- 点击卡片直接回到 App 的主页。
- 配套的「上课提醒」在未来三天按课表提前 10 分钟提醒，重新抓取课表时自动重排。

### 隐私友好

- 首次启动展示系统半模态隐私声明，用户同意后才进入应用。
- 不接入统计、广告或第三方 SDK，不上传任何业务数据。
- 所有账号、密码与缓存均保存在设备本地，可在设置中清除。

## 更新说明

### 0.2.18 — 2026-10-27

- **包名改为 `com.humour.myshangda`**，与原作者仓库的 `com.courier.myshangda` 分开。原因是后者在本机
  没有任何签名材料，只能产出 unsigned 包、还得在 DevEco 里手工签名才能装；换成自己账号下的包名后，
  可以直接用调试证书签名，`hap-sign-tool verify-app` 校验通过，出包即可安装。
- `vendor` 同步改为 `humour213`。
- **上课提醒的跳转包名同步修改**（`Reminders.ets` 的 `PKG_NAME`）。这个常量必须与工程一致，
  漏改会导致点击提醒拉不起应用。
- 已经装过 0.2.17 的设备可**直接覆盖升级**，包名未变，登录态、偏好设置与课表缓存都保留。
- 签名用的是 AGC 调试证书（`com.humour.myshangda`，有效期至 2027-10-21），**绑定 3 台已登记设备**，
  只能在这些设备上安装，不用于公开分发；对外发布仍需申请正式发布证书。

### 0.2.17 — 2026-10-27

- **原版样式的底栏回到「占满整行的一条」，不做胶囊**：0.2.16 用 `barOverlap` + 浮动样式把它变成了
  悬浮药丸，观感跑偏，已撤回。现在仍是 `Tabs` 底部留 24vp（`CLASSIC_BAR_LIFT`）+ 底栏同色填充
  （`CLASSIC_BAR_BG`），底栏高度、图标、配色与安卓 / iOS 端一致，也不会被手势条压住。
- **原生样式真的沉浸了**：`HdsNavigation` 的 `expandSafeArea` 补上 `SafeAreaEdge.BOTTOM`
  （原来只有 TOP）。内容不再止步于安全区上沿，而是一直铺到屏幕最下沿、从「沉浸光感」底栏后面穿过，
  底栏下方不再是一条窗口白底。
- 保留 0.2.15 的其余改动：原生样式下边距 6vp、原版样式底栏不滑动收起、选中态文字与图标同源翻转。

### 0.2.16 — 已回滚（2026-10-27）

- ~~原版样式底栏改成浮层沉浸~~：改动方向对，但观感变成「悬浮胶囊」，与原版不一致，0.2.17 已撤回。
- **保留的结论**：`barFloatingStyle` 的 `barWidth` 只接受具体数值（文档写明 cannot be set in
  percentage），传 `'72%'` 会让整个浮动样式被忽略、`barBottomMargin` 一并失效——这是之前
  12 / 24 / 90 三个值怎么调都没反应的真正原因，以后要动浮层必须传数值。

### 0.2.15 — 2026-10-27

- **原版 App 样式底栏整体抬高**：该样式跑在真全屏沉浸里，窗口不替底栏避让系统手势条，
  底栏会一直贴到屏幕最下沿、下沿被手势条压住。现在给 `Tabs` 留 24vp 底部内边距
  （`CLASSIC_BAR_LIFT`），整条底栏连背景一起上移；底栏自身的高度、图标、配色都不动。
  抬高后露出的那一段用与底栏相同的底色（`CLASSIC_BAR_BG`）填上，底栏与底部之间不再有白条。
- **鸿蒙原生样式的底栏压低一点**：该样式由系统布局、窗口已避让过导航条，12vp 偏高，
  改成 6vp（`BAR_MARGIN_NATIVE`），更贴底但仍不会被手势条压住。
- **原版样式的底栏不再滑动收起**：这个样式的底栏是常驻的，网页里快速上滑 / 下滑
  不再收起或唤出它（原生样式仍保留该交互）。
- **修「文字变蓝比图标慢一拍」**：`Tabs` 内部的选中态在切换动画开始时就会翻转，而图标依赖
  `onChange` 里的 `currentTab`，两者不同源。现在把 `labelStyle` 的 `selectedColor` /
  `unselectedColor` 都交给 `labelColorOf(idx, ...)`，文字与图标同由 `currentTab` 驱动，一起翻转。

### 0.2.14 — 已回滚（2026-10-27）

- ~~「原版 App 样式」的浮层底栏抬高避让导航条~~：真机观感反而偏离安卓/iOS 端，已整条撤销，
  底栏离底距离回到 0.2.13 的 12vp（收起时 -180vp），`EntryAbility` 里的避让区读取一并移除。
- **保留**：社区适配页填上维护者邮箱（`2496548066@qq.com`），点一下直接发信。

### 0.2.13 — 2026-10-27

本版集中在**课表桌面卡片**与**下拉刷新**两块，中间若干次真机试装的迭代合并进这一条。

- **课表卡片改版（新版三种）**：整卡用状态色浅调打底，唯一一张白卡承载「此刻」——
  上课中就显示正在上的这门，没课就显示下一节，今天上完就显示明天第一节。白卡下方只剩
  圆点 + 课名 + 时间，退为次要信息。今天课全上完后整卡切成淡靛蓝的明天预告。
- **旧版列表卡回归（2×2 / 2×4）**：白底 + 彩色块的原版式保留，与新卡并存，长按桌面卡片
  即可二选一。按时间顺序列出还没上完的课，上完一节少一条。
- **卡片只报事实、不下结论**：去掉「上课中 / 下节」这类标签，单纯按时间列课。
- **卡片留白与弧度**：底部留白与左右等宽，滚动区按「外弧半径 − 留白」取内弧，
  两条弧同心平行，内容是弧线裁切而不是被直线切断。
- **课名尽量一行**：卡片不支持官方字号自适应，改为按文字宽度估算字号，
  在 17→12 / 20→14 / 15→12 区间里取能一行放下的最大值。
- **卡片跟着下课时间刷新**：在下课那一刻单独排一次刷新（`setFormNextRefreshTime`），
  不必等系统下次轮询。
- **下拉刷新不再顶出大片空白**：真正的原因是 ArkWeb 的 `overScrollMode` 在活动 Tab 上被开成
  `ALWAYS`，网页滚到顶部会先吃掉手势自己做回弹，再叠加原生刷新位移，两段合起来能撑到半屏。
  改为恒 `NEVER` 后，顶部白区从 237vp 降到 75vp。
- **下拉手感三参数定稿**：触发阈值 64vp、跟手比 0.55（约拉 116vp 才触发）、
  拉伸上限 88vp（怎么甩都撑不开）。

### 0.2.3 — 2026-10-27

- **恢复上次停留的 Tab**：正常退出后再打开，会回到你上次看的那一屏（此前固定落主页）。
  退出登录时不保留现场，重新登录仍落主页。
- **滑动收起底栏**：在网页里快速上滑（往下看内容）时底栏滑出屏幕，1.5 秒后自动回来；
  快速下滑随时唤出。判定用的是**滑动速度**（0.6 vp/ms）而不是距离，
  慢慢拖、微调位置都不会误触发。只改 `barFloatingStyle` 的 `barBottomMargin`，
  底栏是浮层，收起不会让网页重新排版、也不会跳动。
- 切换 Tab、切换外观、退出登录都会立即把底栏展开。

### 0.2.1 — 2026-10-26

## 构建与运行

环境要求：

- DevEco Studio 6.1 及以上
- HarmonyOS SDK 6.1.1（API 24）及以上，目标 API 26
- 一台 HarmonyOS 真机或模拟器

命令行构建：

```bash
hvigorw assembleHap --mode module -p product=default -p buildMode=release --no-daemon
```

产物位于：

```text
entry/build/default/outputs/default/entry-default-signed.hap
```

仓库不包含任何签名证书。首次打开工程时，请在 DevEco Studio 中进入 **File → Project Structure → Signing Configs**，勾选自动签名或配置自己的证书。

安装与启动：

```bash
hdc install -r entry/build/default/outputs/default/entry-default-signed.hap
hdc shell aa start -a EntryAbility -b com.humour.myshangda
```

## 使用说明

1. 首次启动阅读并同意隐私声明。
2. 在登录页输入学校统一身份认证的学号 / 工号与密码，可选择记住密码。
3. 登录成功后进入主页，底部导航可切换消息、审批、主页、通讯录、我的。
4. 设置页可切换界面样式、清理缓存或退出登录。
